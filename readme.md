# 🎱 Streamlit 로또 번호 생성기

Streamlit을 기반으로 동작하는 직관적이고 깔끔한 디자인의 로또 번호 생성기 웹 애플리케이션입니다.

---

## ✨ 주요 기능

* **로또 번호 자동 생성**: 1부터 45까지의 숫자 중 중복 없는 6개의 번호를 무작위 추출하고 오름차순으로 정렬합니다.
* **최대 5개 세트 누적**: 생성 버튼을 누를 때마다 최대 5개 세트까지 화면에 보관되며, 5개를 초과하면 가장 오래된 세트부터 자동 삭제됩니다.
* **실제 로또 공 색상 반영**: 번호 구간별로 실제 동행복권 로또 공의 색상을 반영하여 직관적인 visual을 제공합니다.
  * 🟡 **1~10번**: 노란색
  * 🔵 **11~20번**: 파란색
  * 🔴 **21~30번**: 빨간색
  * ⚪ **31~40번**: 회색
  * 🟢 **41~45번**: 초록색
* **초기화 기능**: 클릭 한 번으로 생성된 모든 로또 번호 세트를 초기화할 수 있습니다.

---

## 🚀 실행 방법

### 1. 가상환경 구성 및 패키지 설치

의존성 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행

아래 명령어를 사용하여 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```

명령어 실행 후 브라우저가 자동으로 열리며 로또 번호 생성기 화면이 표시됩니다. (기본 주소: `http://localhost:8501`)
